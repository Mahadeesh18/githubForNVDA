github for NVDA

Overview

github for NVDA is an accessible add-on for NonVisual Desktop Access (NVDA) that provides a comprehensive interface for managing your GitHub account. It allows you to view and edit your profile, manage your repositories, and explore public repositories on GitHub.

Version Information

  • Add-on Version: 1.0
  • NVDA Minimum Version: 2024.1
  • Last Tested With: NVDA 2026.2

Key Features

1. Profile Management

  • View comprehensive GitHub profile details
  • Edit profile fields (name, location, bio)
  • Copy profile information to clipboard
  • View follower/following statistics

2. Repository Management

  • List all your repositories (up to 100)
  • Sort by name (A-Z or Z-A) or last commit date
  • Real-time search and filtering
  • Fully accessible interface for screen readers

3. Public Repository Explorer

  • Search across all public repositories on GitHub
  • Browse search results instantly
  • Fully accessible search experience

Getting Started

Installation

  1. Download the github for NVDA addon file
  2. Open the file with NVDA or press Enter on it
  3. Click "Install" in the dialog that appears
  4. Restart NVDA for the add-on to become active

First Time Use

When you first open GitHub Manager, you'll be prompted for a GitHub Personal Access Token:

  1. Go to github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Name it something like "NVDA GitHub Manager"
  4. Select scopes: user, repo, gist
  5. Click "Generate token"
  6. Copy the token (you won't see it again!)
  7. Paste it into the NVDA dialog when prompted
⚠️ Important: Keep your token secret! Never share it or commit it to version control.

How to Use

Opening GitHub Manager

Press: NVDA + Shift + G

Main Menu Options

  1. Set or Edit Personal Access Token: Add or update your GitHub authentication token
  2. My Profile: View and edit your GitHub profile information
  3. My Repositories: Browse, sort, and search through your repositories
  4. Explore Public Repositories: Search for repositories across all of GitHub
  5. About & User Guide: View this help documentation
  6. Close: Exit the add-on

Navigation Tips

Keyboard Controls:
  • Tab: Move between buttons and fields
  • Enter/Space: Activate buttons
  • Arrow Keys: Navigate lists and combo boxes
  • Escape: Close dialogs and return to previous menu

Features in Detail

My Profile View

View your complete GitHub profile including:

  • Username and account type
  • Name, bio, and location
  • Public and private repository counts
  • Public and private gist counts
  • Number of starred repositories
  • Follower and following counts
  • GitHub plan type (free, pro, etc.)
  • Account creation date

Edit any of these fields by selecting the "Edit [Field]" button that appears next to editable fields.

My Repositories

Manage your repositories with:

  • Sort Options: Choose from A-Z, Z-A, or by last commit date
  • Search Box: Type to filter repositories in real-time
  • Repository List: Navigate with arrow keys, press Enter for details

Explore Public Repositories

Search GitHub's public repositories:

  1. Type your search query (e.g., "python machine learning")
  2. Press Tab or click the "Search" button
  3. Results will appear in the list below
  4. Navigate with arrow keys to browse results

Troubleshooting

API Error Messages

  • "Error 401": Invalid or expired token. Generate a new one on GitHub
  • "Error 403": Token lacks required permissions. Regenerate with correct scopes
  • "Timeout": Internet connection issue. Check your connection and try again
  • "Search failed": Invalid search query. Try simpler search terms

Add-on Not Responding

If the add-on freezes:

  1. Press Escape to close the current dialog
  2. Try opening GitHub Manager again
  3. If it still doesn't work, restart NVDA

Token Not Saving

  • Ensure NVDA has permission to write to its config directory
  • Try disabling and re-enabling the add-on
  • Check that your token is valid by testing it on GitHub.com
Network Issues? This add-on requires an active internet connection to communicate with GitHub's API.
